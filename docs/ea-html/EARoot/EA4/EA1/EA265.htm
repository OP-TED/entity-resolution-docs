The decision object captures what (integration) action shall be taken given a DeciusionContex. <br/><br/>Integration needed in 2 context<br/>* when a response comes from ERE , we need to  (step 1) store the alternatives + (step 2) automatically accept the top alternative if it is above and (step 3) upsert it into the canonical entity registry<br/>* <br/><br/>* For automated actions  ...<br/>* For user actions ...<br/><br/>The decision-making integration logic is as follows:<br/>1) Accepting the automatic alignment<br/>* confidenceScore of the proposed alignment is left as is.<br/>2) Reassigning the mention to another proposed entity<br/>* confidenceScore of the chosen alignment is set to 1.0<br/>* confidenceScore of the proposed alignment is set to -1.0<br/>* other alternative alignments are note affected<br/>2) Rejecting the automatic alignment<br/>* confidenceScore of both proposed alignment and alternative alignments is set to -1.0<br/><br/>
