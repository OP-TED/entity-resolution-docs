= Annexe B: Use Case Catalogue

This catalogue is the authoritative specification of all externally observable use cases for ERSys, organised at White (business) and Blue (system) levels using the Cockburn format. White-level use cases define business value; Blue-level use cases detail system interactions.

| White-level: Originator submits an entity mention and receives a canonical identifier within the agreed timeout budget.

| xref:AnnexeB-UseCases/ucb11.adoc#uc-b1-1[UC-B1.1: Resolve via ERS API]
