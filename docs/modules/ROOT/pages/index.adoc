= Entity Resolution System Documentation

The Publications Office of the European Union processes thousands of procurement notices daily through the TED ecosystem.
These notices reference real-world entities — organisations, procedures, lots — that may be described differently across submissions yet refer to the same thing.
The Entity Resolution System (ERSys) automatically identifies when different entity representations refer to the same real-world entity and assigns each a stable canonical identifier, so downstream consumers always have a consistent identity even as resolution quality improves over time.

ERSys is a platform of three cooperating components — the Entity Resolution Service (ERS), a pluggable Entity Resolution Engine (ERE), and a Curation Web Application.
For the full capability and authority model, see the xref:ERSys/index.adoc[ERSys Overview].
