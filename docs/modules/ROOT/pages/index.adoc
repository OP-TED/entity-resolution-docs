= Entity Resolution System Documentation

This documentation covers the architecture, technical contracts, and supporting materials for the Entity Resolution System (ERSys).

== Introduction

The Publications Office of the European Union processes thousands of procurement notices daily through the TED ecosystem.
These notices reference real-world entities — organisations, procedures, lots — that may be described differently across submissions yet refer to the same thing.
ERSys addresses this by automatically identifying when different entity representations refer to the same real-world entity and assigning each a stable canonical identifier.

== Entity Resolution System Overview

ERSys is an open-source, scalable entity resolution platform with a pluggable architecture, designed to evolve alongside AI and machine learning technologies.
Its core responsibility is to assign and maintain stable canonical identifiers for entity mentions submitted by external systems, so that downstream consumers always have a consistent, dereferenceable identity even as resolution quality improves over time.

ERSys is composed of three main components:

* *Entity Resolution Service (ERS)* — orchestrates resolution requests, enforces time budgets, persists assignment state, and exposes canonical identifiers through stable APIs.
* *Entity Resolution Engine (ERE)* — the authoritative clustering component that decides whether two entity mentions refer to the same real-world entity. ERSys is designed to work with any conformant ERE implementation.
* *Curation Web Application* — supports human-in-the-loop review and re-evaluation of resolution decisions, with a full audit trail.
