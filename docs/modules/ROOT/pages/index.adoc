= Entity Resolution System Documentation

This documentation describes the Entity Resolution System (ERS), a set of baseline architecture, technical contracts, and supporting materials for managing canonical entity identifiers across distributed systems.

Use this guide to understand the system scope, integration points, and architectural decisions. Start with the table below to navigate to your area of interest.

| xref:ERS-ERE-Contarct/index.adoc[ERS-ERE Technical Contract]
| Specifies the message-based interfaces, idempotent processing rules, and canonical identifier semantics for ERS–ERE communication.

| xref:ERE/ere-dev-guide.adoc[ERE Developer guide]

| xref:AnnexeA-Glossary/index.adoc[Annexe A: Glossary]
