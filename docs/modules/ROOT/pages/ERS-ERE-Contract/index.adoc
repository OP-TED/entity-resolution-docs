= ERS-ERE System Technical Contract

The ERS–ERE technical contract governs the integration between ERS and the Entity Resolution Engine (ERE). It defines the ERE's responsibilities, the messaging channels and request types, the formal data model, and the rules for engine replaceability and canonical identifier derivation. This section is a guide to its parts.
