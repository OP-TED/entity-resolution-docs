= ERS-ERE System Technical Contract

This document specifies the technical contract governing the integration between ERS and the Entity Resolution Engine (ERE). It defines the ERE's responsibilities, the messaging channels and request types, the formal data model, and the rules for engine replaceability and canonical identifier derivation.
