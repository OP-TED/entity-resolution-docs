= Entity Resolution System (ERSys) Baseline Architecture

This section establishes the baseline architecture of the Entity Resolution System, defining its boundaries, actors, capabilities, and the structural and behavioural patterns that govern it. It records what ERSys guarantees, how it is built, and the authority model that drives all implementation decisions.
